# データの仕様

## データの種類

| データ           | 作るもの                               | 置き場所                                                                               | スキーマ                                          |
| ---------------- | -------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 祭り             | 調査（Claude Code と調査スキル）       | `data/festivals/{id}.json`（1件1ファイル）                                             | `FestivalSchema`                                  |
| 旅程             | 接客エージェント（`update_itinerary`） | 版ごとに保存先（既定はメモリ、本番は Firestore）に保存（[ログインと保存](account.md)） | `ItinerarySchema`                                 |
| 画面へのイベント | 接客サーバーのフック                   | SSE で送るだけ                                                                         | `SseEventSchema`（[API と SSE イベント](api.md)） |
| クイズ           | 祭りのデータの出典つきの小話から作る   | `data/quiz/festival-quiz.json`                                                         | `QuizBankSchema`                                  |

どれも `packages/schema` の Zod のスキーマを唯一の定義にし、サーバー・画面・スクリプトで共有します。旅程の中身は [旅程の仕様](itinerary.md) にあります。

## 3つの決まり

### 1. 出典は必須

すべての出典（`Source`）は、URL・確認した日・確度の3つを持ちます。

```json
{ "url": "https://…", "checkedAt": "2026-04-01", "confidence": "official" }
```

| 確度           | 意味                                    | 画面のバッジ     |
| -------------- | --------------------------------------- | ---------------- |
| `official`     | 主催者・自治体の情報で確認した          | 緑「公式で確認」 |
| `corroborated` | 公式はないが、2つ以上の情報源で一致した | 青「複数で確認」 |
| `single`       | 1つの情報源だけ                         | 黄「情報源1つ」  |
| `inferred`     | 推定。確定した旅程には入れない          | 灰「推定」       |

祭りそのもの・開催回・小話・地元の味・周辺の場所は、出典がないとスキーマで不正になります。参加の仕方と決まりとアクセスは、分かっている項目が1つでもあれば出典が要ります。

### 2. 分からないことは推測で埋めない

- 開始時刻・雨天の扱い・営業時間など、分からない値は `null` にし、何が分からないかを `gaps` に書く
- **参加の仕方と決まりの各項目は省略できません。** 値か `"unknown"` を必ず書きます。祭りから探すときは、`"unknown"` を条件に合うとはみなしません
- 申し込み方法（`howToJoin`）だけは、見学のみの祭りでは当てはまらないので `null` にします

### 3. 知らない項目は入れない

祭りのデータは、スキーマにない項目があると不正になります。綴りの誤りに気づけるようにするためです。

## 祭り（Festival）

祭り本体（毎年ほぼ同じ情報）と開催回（年ごとの情報）を分けて持ちます。

| 項目             | 中身                                                                                    |
| ---------------- | --------------------------------------------------------------------------------------- |
| `id`             | 小文字の英数字とハイフン。ファイル名と同じにする                                        |
| `name`           | 日本語の名前（`ja`）と、あれば英語の名前（`en`）                                        |
| `category`       | 種類：花火・山車・神輿・踊り・火祭り・灯籠・芸能・神事・市・その他                      |
| `municipalities` | 開催地の都道府県と市町村。川をはさむ祭りなど、都道府県をまたぐこともある                |
| `venue`          | 会場の名前と緯度・経度                                                                  |
| `scaleTier`      | 規模ランク（XS・S・M・L）。打ち上げ数や山車の数で決め、来場者数の公表値は参考にとどめる |
| `popularity`     | 知名度（下の表）                                                                        |
| `listedIn`       | 載っている大手の観光サイト                                                              |
| `highlights`     | 見どころ（1つ以上）                                                                     |
| `trivia`         | 待ち時間に出す小話。60字以内で、出典つき                                                |
| `etiquette`      | 参加の仕方と決まり（下の表）                                                            |
| `occurrences`    | 開催回（下の表）。1つ以上                                                               |
| `access`         | 最寄り駅と徒歩の時間、主要駅からの所要時間、駐車場、交通規制                            |
| `food`           | 屋台の有無と、地元の味                                                                  |
| `nearby`         | 祭りの前後に寄れる観光・食・休憩の場所                                                  |
| `sources`        | 祭りそのもの（名前・会場・種類）の出典                                                  |
| `gaps`           | 調べても分からなかったこと                                                              |
| `optOut`         | 祭りを運営する方から掲載停止の依頼があった。省略すると `false`                          |

### 知名度

大手の観光サイトに載っている数から付けます。こだわりの「定番どころ」「穴場」の判断に使います。

| 値         | 意味                                 |
| ---------- | ------------------------------------ |
| `major`    | 多くの大手の観光サイトに載る（定番） |
| `regional` | 一部に載る                           |
| `local`    | ほとんど載っていない（穴場）         |

### 参加の仕方と決まり（Etiquette）

見学だけか加われるか、決まり、服装、持ち物、危険度、写真の可否を持つ項目です。利用者にそのまま見せる画面はなく、祭りから探すときの絞り込み（参加できる・写真・危険度）と自由記述の照合、候補のカードの「参加できる」の目印に使います。

| 項目            | 中身                                                                                               | 分からないとき                   |
| --------------- | -------------------------------------------------------------------------------------------------- | -------------------------------- |
| `participation` | 見学のみ（`watch_only`）・だれでも加われる（`join_open`）・申し込みが必要（`join_by_application`） | `"unknown"`                      |
| `howToJoin`     | 申し込みや参加の方法。見学のみなら `null`                                                          | `"unknown"`                      |
| `rules`         | ルールとマナー                                                                                     | `"unknown"`                      |
| `dress`         | 服装                                                                                               | `"unknown"`                      |
| `bring`         | 持ち物                                                                                             | `"unknown"`                      |
| `risk`          | 危険度（低・中・高）と、その理由                                                                   | `"unknown"`                      |
| `photo`         | 写真：撮ってよい・制限がある・撮らない、と補足                                                     | `"unknown"`                      |
| `sources`       | 参加の仕方と決まりの出典                                                                           | すべて分からないときだけ空でよい |

### 開催回（Occurrence）

| 項目              | 中身                                                                |
| ----------------- | ------------------------------------------------------------------- |
| `date`・`endDate` | 開催日。複数日にわたるときは終わりの日も                            |
| `start`・`end`    | 開始と終了の時刻（HH:MM）。分からなければ `null`                    |
| `status`          | 発表済み（`announced`）・例年からの見込み（`expected`）・延期・中止 |
| `rainPolicy`      | 雨天の扱い。分からなければ `null`                                   |
| `sources`         | 開催回の出典（1つ以上）                                             |

**開催が確認できている**のは、発表済みで、公式か2つ以上の情報源で確かめられた開催回だけです（`isOccurrenceConfirmed`）。それ以外の祭りは、候補を出す前に Web で開催を確かめ、公式以外の情報源などで確かめられれば「要事前確認」として出します。どこからも情報が取れなければ候補に出しません（[候補を出す前の確かめ](agent-runtime.md#候補を出す前の確かめ)）。

### 周辺の場所（NearbySpot）

店や観光地は、自分の言葉で書いた120字以内の要約と、出典のリンクだけを持ちます。文章や画像はコピーしません。営業時間（`hours`）と定休日（`closedDays`）は、分からなければ `null` にし、定休日がなければ空の配列にします。

## クイズ（Quiz）

待ち時間の窓に出す選択式のクイズです。問いと答えは、出典（URL・確認した日・確度）を書ける情報だけで作り、推測で作りません。祭りのデータにある情報から作るときは、その出典をそのまま `source` に入れます（テストで、祭りのデータにある出典と同じかを確かめます）。

| 項目          | 内容                                                |
| ------------- | --------------------------------------------------- |
| `id`          | 英小文字・数字・ハイフン。重ねない                  |
| `festivalId`  | 話の元になった祭りの ID（掲載中の祭りだけ）。省略可 |
| `question`    | 問い                                                |
| `choices`     | 選択肢（2〜4つ、同じものを重ねない）                |
| `answer`      | 正解の選択肢の位置（0 から）                        |
| `explanation` | 答えたあとに出す短い解説                            |
| `source`      | 出典（推定 `inferred` は使わない）                  |

## 情報の鮮度

すべての情報に最後に確かめた日（`checkedAt`）があります。期限を過ぎたものは、データの検証（`pnpm validate:data`）が警告として出し、調べ直す対象にします。開催日と時刻は、これとは別に、候補を出す前と確定の前に公式の情報で確かめます（[候補を出す前の確かめ](agent-runtime.md#候補を出す前の確かめ)）。

| 情報                                                         | 期限  |
| ------------------------------------------------------------ | ----- |
| 直近4週間の開催日・時間                                      | 7日   |
| 先1〜3か月の開催日                                           | 30日  |
| 周辺の店や施設の営業時間                                     | 30日  |
| それより先の開催日、由来・特徴・見どころ・参加の仕方と決まり | 365日 |
