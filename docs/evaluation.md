# 評価

3つの壁（情報・作法・計画）をどれだけ取り除けているかを、数字で示します（[課題](problem.md#壁をどう取り除くか)）。数字は、だれでも同じ手順で出し直せるものだけを載せます。

## 何を測るか

| 壁   | 指標                                         | 測り方                                                                                                                                       | 状態   |
| ---- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 情報 | 穴場（知名度 `local`）の割合                 | 祭りのデータのうち、大手の観光サイトにほとんど載っていない祭りの割合。検索の上位に出る定番との違いを示す                                     | 測った |
| 情報 | 次の開催を公式か複数の情報源で確認できた割合 | 次の開催回が、発表済み（`announced`）で、出典の確度が `official` か `corroborated` の祭りの割合（スキーマの `isOccurrenceConfirmed` と同じ） | 測った |
| 作法 | 作法の項目が分かっている割合                 | 作法の7項目のうち `"unknown"` でないものの割合。見学だけの祭りの `howToJoin`（当てはまらない）は分母から除く                                 | 測った |
| 情報 | 1件あたりの `gaps` の数                      | 調べても分からなかったことの数の平均。推測で埋めずに残した数で、少ないほどよいとは限らない                                                   | 測った |
| 情報 | 条件に合う祭りを候補に出せた割合             | 記録した相談（[`data/samples/`](../data/samples/README.md)）を再生し、条件に合う祭りが候補に入った相談の割合                                 | 準備中 |
| 計画 | 旅程の検証で落ちた割合                       | 記録した相談で作った旅程のうち、旅程の検証（開催時間・移動・営業時間）でエラーになった割合                                                   | 準備中 |

「次の開催回」は、基準の日に終わっていない開催回のうちいちばん早いものです。すべて過ぎていれば、いちばん新しい開催回を使います。掲載停止（`optOut: true`）の祭りは数えません。

## 出し直し方

```bash
pnpm evaluate:data                       # 今日（日本の日付）を基準に集計する
pnpm evaluate:data --today 2026-11-04    # 基準の日を指定する
```

集計は [`scripts/evaluation.ts`](../scripts/evaluation.ts)、そのテストは架空の祭りで [`scripts/evaluation.test.ts`](../scripts/evaluation.test.ts) に書いてあります。

## 結果

基準日 2026-11-04、祭り 21 件（掲載停止を除く）。

| 指標                                         | 結果            |
| -------------------------------------------- | --------------- |
| 穴場（知名度 `local`）の割合                 | 9 / 21（43%）   |
| 次の開催を公式か複数の情報源で確認できた割合 | 10 / 21（48%）  |
| 作法の項目が分かっている割合                 | 69 / 135（51%） |
| 1件あたりの `gaps` の数                      | 12.5            |

次の開催回の出典の確度：

| 確度           | 祭り |
| -------------- | ---- |
| `official`     | 20   |
| `corroborated` | 0    |
| `single`       | 0    |
| `inferred`     | 1    |

作法の項目ごとの、値が分かっている祭り：

| 項目            | 分かっている祭り |
| --------------- | ---------------- |
| `participation` | 20 / 21（95%）   |
| `howToJoin`     | 9 / 9（100%）    |
| `rules`         | 13 / 21（62%）   |
| `dress`         | 0 / 21（0%）     |
| `bring`         | 2 / 21（10%）    |
| `risk`          | 19 / 21（90%）   |
| `photo`         | 6 / 21（29%）    |

### 読み方

- 次の開催回の出典は 21 件中 20 件が公式ですが、確認できた割合が 48% にとどまるのは、次の開催がまだ発表されておらず、例年の傾向からの見込み（`expected`）の祭りがあるためです。発表されたら、週に1回の確かめ直しで `announced` に変わります
- 作法では、服装・持ち物・写真が公式の情報に書かれていないことが多く、`"unknown"` のまま残っています。しおりでは「不明」と出し、推測では埋めません
