# 出発の駅の一覧

相談の聞き取りで、出発する駅の候補を出すための一覧です。ファイルは [`data/stations/stations.json`](../data/stations/stations.json) にあり、画面は出発地の段階を開いたときに初めて読みます。

## 出典と利用条件

| 項目       | 内容                                                                                                                                |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| データ     | 国土数値情報（鉄道データ）N02 の 2025年度版（全国、`N02-25_GML.zip`）の駅（Station）。データ基準年月日は 2025年12月31日            |
| 提供       | 国土交通省                                                                                                                          |
| ページ     | <https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html>                                                                  |
| 利用条件   | 2020年以降のデータはオープンデータ（CC BY 4.0）。[国土数値情報の使用許諾条件](https://nlftp.mlit.go.jp/ksj/other/agreement_01.html) |
| 取得した日 | 2026-11-03                                                                                                                          |
| 確認した日 | 2026-11-03（利用条件のページと、データのページで確認）                                                                              |

出典の表記（画面の一覧のファイルの `source` にも同じものを入れています）：

> 「国土数値情報（鉄道データ）」（国土交通省）（<https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html>）を加工して作成

使用許諾条件に沿って、次のことを守ります。

- 加工したこと（下の「加工の中身」）を書き、国が作ったように見せない
- 一覧は候補を出すためだけに使い、駅や路線の正しさの保証には使わない。旅程の行き方は、接客サーバーのツールの結果で決める

## 加工の中身

- 一覧に入れるのは駅名と路線の説明だけ。位置（座標）は駅をまとめるかを決めるためだけに使い、駅コードとともに一覧には入れない
- 同じグループコードの駅（乗り換えできる駅）と、1.5km 以内にある同じ名前の駅を1つにまとめ、路線を「運営会社 路線名」で3つまで添える（多い駅は「ほかN路線」）
- 駅名の全角の英数字を半角にそろえる
- 遠くにある同じ名前の駅（別の土地の駅）は、別の候補として残す。見分けるのは添えた路線
- 2025年度版では、駅の地物 10,234 件から 9,006 駅の候補になり、ファイルは約 500KB（gzip で約 90KB）

## 作り直す手順

1. 上のページから全国の版（`N02-25_GML.zip`）を取る。zip はリポジトリの外に置き、コミットしない
2. zip のパスと取得した日を指定して、一覧を作る。スクリプトは zip の中の `UTF-8/N02-25_Station.geojson` を読む（展開は要らない）

   ```bash
   pnpm build:stations --zip path/to/N02-25_GML.zip --retrieved 2026-11-03
   ```

3. 新しい版のページに変わったときは、[`scripts/build-stations.ts`](../scripts/build-stations.ts) の `SOURCE_URL` と、この文書の表を直す。利用条件が変わっていないかも、使用許諾条件のページで確かめる

作る処理は [`scripts/stations.ts`](../scripts/stations.ts)、zip を読む処理は [`scripts/lib/zip.ts`](../scripts/lib/zip.ts) にあり、テストは架空の駅と小さな zip で書いています。
