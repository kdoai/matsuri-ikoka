# ADR 0015：組んだ旅を旅の日まで残し、あとから開いて続けられるようにする

- 状態：採用（[ADR 0011](0011-owner-isolation.md) の「前に渡したしおりの URL は開けなくなる」を置き換える）

## 背景

組んだ旅を失いやすく、残した旅もあとから使いにくかった。

- 相談の途中の状態は最後に使ってから6時間で消えるのに、旅程は30日残る。翌日に「この旅を残す」を押すと、相談がないので 404 になった
- 画面は相談の ID を端末に控えないので、再読み込みやスマホのタブの破棄で、組んだ旅程が画面から消えた。サーバーが相談を覚えていないと、こだわりを切り替えただけで旅程が画面から消えた
- 残さなかった旅程と共有は30日で消えるので、3か月先の祭りのしおりの URL は、旅の当日に開けなかった。期限も画面に出なかった
- 残した旅の操作は「しおりを開く」と「消す」だけで、店に戻して続きを相談できなかった。確定する前の旅は「まだ確定していない旅程です」で行き止まりになった
- ログインせずに組んで送ったしおりの URL は、あとでログインして持ち主が付くと、予告なく 404 になった（ADR 0011）

## 判断

- **期限は「最後の保存から30日」と「旅の最終日の3日後」の遅い方**：残さなかった旅程・しおりの共有・旅程を持つ相談に同じ決まりを使う。計算は `domain/retention.ts` の関数にし、保存の口は保存のときに期限を書く。旅程の期限は、保存し直しても縮めない
- **旅程を持つ相談は、旅程と同じ期限まで残す**：翌日以降も、その相談から旅を残し、続きを相談できる。旅程のない相談は、いままでどおり6時間で消す
- **相談の ID を端末に控えて戻す**：画面は相談の ID を `localStorage` に控え、店に入るときに `POST /api/session/resume`（決まりは「相談の持ち主」）で段階・こだわり・旅程を戻す。控えた ID だけではほかの人の相談を開けない（持ち主の確かめはサーバーの `Consultations.open`）。会話の文章は残していないので、旅程のない相談は戻さない
- **残した旅を店に戻す**：`POST /api/trips/:id/resume`（決まりは「ログインした持ち主」）で、旅程の条件とこだわりを持った新しい相談を始める。確定する前の旅も開ける。しおりの「まだ確定していない」の画面には、店で続ける入口を出す
- **前に渡したしおりの URL を残す**：持ち主のなかった旅程に持ち主が付いたら、付く前の最新の版（`publicVersion`）を、その期限（`publicExpiresAt`）まで `/shiori/{旅程の ID}` で出す。付いたあとの版は持ち主にしか見せず、旅程の API（`/api/itinerary/:id`）では付く前の版も読ませない。持ち主が旅を消すと、この URL も開けなくなる
- **画面で旅程を消す前に確かめる**：設定の「最初から」は、旅程があるときに確かめる。サーバーが相談を覚えていないときは、画面の旅程を読めるまま残す。しおりの画面に「この旅を残す」を置く
- **期限を見せる**：しおりの画面の上に「この URL は〜まで開けます」と出す。見つからないときの文は、期限を過ぎたこともありうると伝え、開き直し方を添える（あるかどうかは見せない）

## 検討した案

- **翌日の「残す」のために、旅程の ID で残せるようにする**：しおりの URL を受け取っただけの人が、他人の旅程を自分のものにできてしまう。相談の ID で指す決まり（ADR 0005）を保つため、相談のほうを長く残す
- **前に渡した URL は、持ち主が付く前に知らせて切る**：知らせても、受け取った人の手元の URL は切れる。付く前の版をそのまま出し続けても、すでに URL で見せていた中身なので、新しく見せるものはない
- **旅程を持つ相談を残す期限を、すべての相談で長くする**：旅程のない相談には条件と出発地だけが残り、使い道がないまま長く残る
- **期限を旅の最終日だけで決める**：旅の日が分からない旅程や、近い旅で保存した直後に消えてしまう

## 結果

- 良い点：再読み込みや翌日でも、組んだ旅を失いにくい。先の祭りでも、当日にしおりを開ける。残した旅から続きを相談できる。渡した URL が予告なく切れない
- 引き受けること：
  - 旅程を持つ相談の途中の状態（条件・こだわり・出発地）が、最長で旅の最終日の3日後まで残る。「旅とログインの記録をすべて消す」では、いままでどおり期限を待たずに消す
  - 付く前の版を出し続けるので、ログインする前に渡した URL を止めたいときは、旅を消す
  - 付く前の版も、版が20を超えて古い版が消えると開けなくなる
  - 端末に控えるのは相談の ID だけで、同じ端末を使うほかの人は、ログインなしの相談の続きを開ける（いままでも、相談の ID を知っている人は続けられた）。ログインして使った相談は、その人がログインしていなければ開けない
  - 期限の項目のない前の形の保存は、旅程は最後の保存から30日、相談は6時間として読む
