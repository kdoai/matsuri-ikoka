# ADR 0014：ガイドを緊急の連絡の窓口にしない

- 状態：採用
- [ADR 0013](0013-guide-conversation.md) の「緊急の案内はコードが出し、断らない」を置き換える

## 背景

ADR 0013 では、ガイドへの発言の言葉で緊急を見分け、モデルも保存の口も待たずに公的な連絡先（119・110）を先に送り、上限や混雑でも断らないことにした。会話の窓には、話せないときも連絡先の欄を出していた。

ガイドは祭りの旅をする人のための道具で、緊急の連絡の窓口にはならない。見分けの言葉は広く取るので、ふつうの相談（「熱中症の対策は？」など）にも当たり、連絡先や決まった文が混ざる。緊急の発言だけ別の経路で受けるので、断り方や保存の待ち方も二通りになっていた。

## 判断

- 画面に公的な連絡先の欄を持たない。サーバーも発言の言葉で緊急を見分けず、`guide.emergency` のイベントを送らない
- 上限・混雑・前の返事の途中・相談がないときは、どの発言も同じく HTTP の応答で断る
- ガイドは体調や事故の診断と判断をしない。命にかかわりそうなときは、返事の中で公的な番号への電話を勧める（プロンプトで伝える）

## 結果

- ふつうの相談に連絡先や決まった文が混ざらない
- 発言の経路が1つになり、断り方と保存の待ち方がそろう
- 続きの要約の話題の `trouble` は、保存してある要約を読めるようにスキーマに残す

## 検討した案

- **連絡先の欄だけを画面に残す**：使う場面がない欄を常に出すことになり、話せないときの窓が分かりにくい。とらない
