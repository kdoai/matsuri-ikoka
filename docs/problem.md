# 課題

## 課題の芯

祭りは交流の場です。小さな祭りほど、本当は外の人とつながって盛り上がりたいと考えています。自分たちだけで楽しみたいと思っている祭りは、多くありません。

それでも、小さな祭りには外へ届ける手段がありません。宣伝しても、届くのはいつもの地元の人だけです。そして行きたい人の側には、**情報と計画**の2つの壁があります。

だから、祭りと外の人を「つなぐ役」が要ります。MATSURI IKOKA は、祭りの側に手間をかけずにその役を担い、2つの壁を旅の前に取り除く AI の旅行代理店です。機能を足すときは、どの壁を取り除くためのものかを先に考えます。

## 祭りの側：来てほしいのに、届ける手段がない

経済産業省が2025年に行った実証調査では、話を聞いた全国10の祭りの主催者が、いずれも外からの参加の受け入れに前向きでした。受け入れにあたっての不安として挙がったのは、言語への対応（いちばん多かった）、しきたり（ルールやマナー）を守ってもらえるか、安全の管理で、あわせて情報の発信のしかたも課題に挙がっています。外の人に来てほしくない、という声ではありません。

小さな祭りの情報は、町の広報や観光協会のページ、地元の掲示に散らばっています。宣伝しても届くのはいつもの地元の人だけで、外の人に届ける手段がありません。

## 行く人の側：2つの壁

### 情報の壁

大手の観光サイトや検索の上位に出るのは、名の知れた祭りが中心です。小さな町の祭りは、外の人には見つけにくいままです。見つけても、今年の日時や雨の日の扱いが確かかどうか分かりません。

### 計画の壁

祭りは開催の時間が決まっていて動かせません。そこから逆算して、移動、食事、休憩、帰りの混雑の避け方までを組むのは手間がかかります。営業時間や定休日を1つずつ確かめる必要もあります。

## つなぐ役として

祭りの側に新しい手間をかけないことを大事にします。公開されている情報から調べて出典を付けて載せるので、祭りの側が登録や更新をしなくても、外の人に届きます。そのうえで、主催者の不安に次のように応えます。

| 主催者の不安 | MATSURI IKOKA がすること                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------------------------- |
| 言語         | 画面の言葉を、日本語と英語で切り替えられるようにする                                                                |
| 安全の管理   | 帰りの混雑の避け方を旅程に入れる。旅の間の体調や事故の相談には、ガイドが公的な連絡先を先に出す                      |
| 情報の発信   | 祭りの情報を、出典つきで外の人に届ける。祭りを運営する方は、掲載や情報提供の依頼・訂正・掲載停止を Issue から頼める |

掲載をやめたいという依頼には、理由を問わずすぐに応じます。

## 壁をどう取り除くか

壁は **型・テスト・数字** の3つで守ります。型は [`packages/schema`](../packages/schema)、数字の測り方と結果は [評価](evaluation.md) に置きます。

| 壁               | 型で守る                                                                                             | 機能                                                               | テストで守る                                     | 数字で示す                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------------------- |
| 情報             | 出典（URL・確認した日・確度）を必須にする。分からない項目は推測で埋めず、`null` にして `gaps` に書く | 祭りの発見、出典と確度のバッジ、確定前の再確認                     | 出典のない祭りはスキーマで不正になる             | 祭りを見つけられた割合、検索の上位との違い、公式で確認できた割合 |
| 計画             | 旅程で、祭りの開催時間を動かせない予定として持つ。移動時間は目安としてしか持てない                   | 旅程、地図、会話での修正、しおり、旅のガイドと見回り               | 日程のルール・到着の余裕・旅程の検証の単体テスト | 計画にかかる時間（手作業との比べ）                               |
| 祭りとのつながり | 掲載停止（`optOut`）を持つ                                                                           | 掲載・情報提供の依頼、訂正、掲載停止の窓口（Issue のテンプレート） | 掲載停止の祭りは検索に出ない                     | —                                                                |

## 想定する利用者

祭りのある町に住んでいない人を想定します。地元の人はすでに祭りを知っているからです。週末のお出かけから数泊の旅まで、知らない町の祭りに行ってみたい人、家族や友だちと行く先を探している人が中心です。

## 数字と出典

経済産業省の2025年の実証調査（祭りを体験型の観光につなげるための調査）から：

- 全国10府県の10の祭りの主催者に話を聞いたところ、すべての主催者が、外からの参加の受け入れに前向きだった
- 受け入れの不安は、言語への対応がいちばん多く、しきたりを守ってもらえるか、安全の管理が続いた。情報の発信のしかたも共通の課題に挙がった
- 関東・関西に住む人への調査では、祭りに参加してみたい人があわせて約8割、見学してみたい人は9割を超えた
- 台湾・香港・タイに住む人への調査では、92% が祭りへの参加に意欲を示した一方、過去の訪日旅行で祭りに参加したことがある人は 14.2% だった

行きたい人も、来てほしい祭りもあるのに、出会えていないことが分かります。
