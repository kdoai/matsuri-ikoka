# 音の素材

画面の BGM（`apps/web/src/ui/sound.ts` の `useBackgroundMusic`）が使う曲です。効果音は素材を持たず、その場で合成しています。

| ファイル          | 中身                                                                                                  |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| `bgm_wadaiko.mp3` | 和太鼓の合奏。太鼓のリズムを主にした、歌なしの祭りの曲（約90秒、MP3 約196kbps 48kHz、ジャケットの画像つき） |
